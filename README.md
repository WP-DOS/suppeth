# Suppeth

A standalone WordPress block theme from [WP-DOS](https://github.com/WP-DOS). Native blocks, locally bundled fonts, editable header and footer patterns, and optional sidebar templates. No parent theme or build step is required.

## Requirements

- WordPress 7.1 or later
- PHP 7.4 or later

## Install

Clone this repository into `wp-content/themes/suppeth`, then activate **Suppeth** under **Appearance → Themes**. Customize templates, patterns, and styles in **Appearance → Editor**.

## Contribute

Work on a feature branch and open a pull request into `main`. Direct pushes to `main` are blocked.

The [WP-DOS site repository](https://github.com/WP-DOS/wp-dos.com) consumes this theme as a submodule and contains its development checks and packaging tools. After merging a theme change, update that repository's submodule commit through a pull request into `develop`.
