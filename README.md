# Suppeth

A free standalone WordPress block theme from [WP-DOS](https://github.com/WP-DOS), designed as a plain, usable starting point for Full Site Editing. No parent theme or runtime build step is required.

## Install

Clone into wp-content/themes/suppeth or install dist/suppeth.zip generated by the [development workflow](docs/development.md). Activate Suppeth under Appearance → Themes and customize it under Appearance → Editor.

Metadata currently declares WordPress 7.1+ and PHP 7.4+; see [compatibility evidence](docs/development.md#compatibility-evidence) before interpreting this as a tested version matrix.
