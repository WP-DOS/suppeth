A minimal standalone FSE theme. No parent theme, remote font requests, or production build dependencies. DM Sans, Manrope, and JetBrains Mono are bundled locally and registered through theme.json. Small optional scripts enhance image descriptions and animate native Details blocks, respecting reduced-motion preferences.

== Installation ==
Upload the packaged suppeth.zip under Appearance > Themes > Add New > Upload Theme, then activate Suppeth.

== Customization ==
Use Appearance > Editor for content and experiments. Move shared template and style changes into Git before deployment: database overrides take precedence over theme files.
