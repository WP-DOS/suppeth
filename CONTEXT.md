# Suppeth

Suppeth is WP-DOS's free WordPress block theme for building individually designed sites through Full Site Editing.

## Language

**Suppeth**:
A standalone block theme with a plain, usable starting point and editable site structure.

**Block theme**:
A WordPress theme whose site templates are composed of blocks and editable through the Site Editor.
_Avoid_: FSE theme as the technical theme type

**Full Site Editing (FSE)**:
WordPress's block-based site customization capabilities, including templates, template parts, and Global Styles.

**Blank slate**:
A restrained, usable starting design rather than an unstyled or incomplete site.

**Bundled pattern**:
An editable block composition distributed with Suppeth, which may use its own presets and styling.

**Portable pattern**:
A reusable composition intended for different block themes, preserving structure while adopting the destination theme's styling.
